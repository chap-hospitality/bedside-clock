# Bedside Clock

นาฬิกาหัวเตียงสำหรับ iPhone รุ่นเก่า (iOS 10 / Safari 10) — เวลา วันที่ภาษาไทย สภาพอากาศ (Open-Meteo) รูปพื้นหลัง และโหมดกลางคืน

- เปิดลิงก์ GitHub Pages ใน Safari → Share → Add to Home Screen
- รูปพื้นหลังที่ใส่ใน `photos/` จะเป็นสาธารณะ — ใส่ชื่อไฟล์ใน `photos/photos.json` เช่น `["a.jpg","b.jpg"]`
- รูปส่วนตัว: อัปจากปุ่ม ⚙︎ ในเครื่อง (เก็บใน iPhone เท่านั้น)
